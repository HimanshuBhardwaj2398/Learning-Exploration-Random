Rebinding say_whee

Why from quiet_night import say_whee hands you the wrapped function, not the def you wrote. Step through the file the way Python runs it.

quiet_night.py
from datetime import datetime
def not_during_the_night(func):
def wrapper():
if 7 <= datetime.now().hour < 22:
func()
else:
pass # neighbors are asleep
return wrapper
def say_whee():
print("Whee!")
say_whee = not_during_the_night(say_whee)

>>> from quiet_night import say_whee
>>> say_whee()

The line say_whee = not_during_the_night(say_whee) is exactly what writing @not_during_the_night above the def does. A decorator isn't magic — it's this name-rebinding, spelled with an @.
