Sudoku in three sets

The whole check is one question asked three times — have I seen this digit here before? The only trick worth learning is how (r // 3, c // 3) turns a cell into its box.

01 One rule, three times

Three constraints, three families of sets

A board is valid when no digit repeats inside a row, inside a column, or inside a 3×3 box. That’s the same question three ways: have I already placed this digit in this unit?

“Have I seen it?” is exactly what a set answers in O(1). So you keep three families of sets — one per row, one per column, one per box. Every filled cell checks in against its three sets, then signs the register. The first collision anywhere means invalid; get to the last cell clean and it’s valid.

Row set — one per row, keyed by r
Column set — one per column, keyed by c
Box set — one per 3×3 block, keyed by (r//3, c//3)

Every cell lives at the crossing of exactly one row, one column, and one box — so each digit is checked against precisely three sets, no matter where it sits.

02 The box trick

Turning a cell into its box

A cell’s row and column are just r and c — no work. The box needs one small move. Picture the nine boxes as their own 3×3 grid: box-row 0/1/2 top to bottom, box-col 0/1/2 left to right.

Rows 0,1,2 all live in box-row 0; rows 3,4,5 in box-row 1; rows 6,7,8 in box-row 2. That grouping-by-threes is precisely what integer division does: r // 3. Same for columns with c // 3. So a cell’s box is the pair (r // 3, c // 3) — nine possible pairs, one per box.

Click any cell to watch its coordinates collapse into a box.

rows → box-row
columns → box-col

i // k is the general “which bucket of size k” move — spot it and grid problems get much friendlier. Prefer a single number? 3*(r//3) + c//3 gives box 0–8.

03 Watch the scan

One pass, three checks per cell

Sweep top-left to bottom-right, skipping blanks. For each digit, look in its row, column, and box sets. Already there? Stop — invalid. Otherwise add it to all three and move on. The valid board runs clean; each clash board trips a different one of the three checks — watch which set flashes red.

04 Carry these

    
What makes it elegant

    

      
01
Three constraints reduce to one primitive: “seen before in this unit?” A set answers that in O(1) and says what you mean — reach for it over a counter you compare against 1.

      
02
Give each unit its own state. A cell (r, c) belongs to row r, column c, and box (r//3, c//3) — three keys, three sets it checks into.

      
03
Floor division is the bucketing move: i // k collapses fine coordinates into groups of k. The same trick tiles up in grids, pagination, time buckets, and sharding.

      
04
One pass, bail on first conflict — no need to count everything and inspect totals afterward. O(81) time, O(81) space, done.
